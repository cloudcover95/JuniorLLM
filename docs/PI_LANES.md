# Pi lanes

JuniorLLM owns the JuniorOS rails plus two sibling Pi repos. All follow the same rails.

| Repo | Rails doc |
|------|-----------|
| cloudcover95/JuniorLLM | `rails/RAILS_INDEX.md` |
| cloudcover95/JuniorPiThon | `docs/RAILS.md` |
| cloudcover95/JuniorPiPython | `docs/RAILS.md` |

JuniorHome is out of lane.

## Rules

- Additive only: never delete, never force-push.
- No GitHub Actions.
- No model pulls.
- Local services bind to `127.0.0.1` only.
- One slice per run: one pull, one additive file, one push.
