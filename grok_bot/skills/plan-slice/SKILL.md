# Plan slice

1. Open `rails/linux/ROADMAP.md` and `grok_bot/GOTCHAS.md`.
2. Choose ONE slice that unblocks a fresh clone or JuniorOS overlay.
3. Write 5 bullets: goal, files, port, test command, done-check.
4. If >8 files or >1 repo *required*, status=`needs_split` and stop.
5. Do not start coding until the plan exists in the receipt draft.
